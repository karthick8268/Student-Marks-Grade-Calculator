Student Marks, Percentage and Grade Calculator

A beginner-friendly Python project that calculates a student's total marks, percentage, grade, and academic performance based on the marks entered for each subject.

Features

- Accepts the student's name.
- Accepts the number of subjects.
- Collects marks for each subject.
- Calculates total marks and percentage.
- Assigns a grade based on the percentage.
- Displays an academic performance remark.
- Rounds the percentage to two decimal places.

Technologies Used

- Python 3
- VS Code

Grading System

Percentage| Grade| Performance
90% and above| A+| Outstanding
80%–89.99%| A| Excellent
70%–79.99%| B| Very Good
60%–69.99%| C| Good
50%–59.99%| D| Average
Below 50%| F| Needs Improvement

How to Run

1. Install Python 3.

2. Download or clone this repository.

3. Open the project folder in VS Code or a terminal.

4. Run the following command:
   
   "python main.py"

5. Enter the student name, number of subjects, and marks when prompted.
